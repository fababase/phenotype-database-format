# Where the data is

Every known dataset in the [phenotype database format](../schema/schema.md), and where to get it.

Before you make new IDs for germplasm, seed lots, traits, climate variables or features, look in the Germplasm, SeedLot, PhenotypeDescription, ClimateDescription and Features tables of these datasets, and reuse the IDs that are already there. See [Identifiers](../schema/schema.md#identifiers).

The datasets are on [Zenodo](https://zenodo.org). Some are open to everyone. Others belong to ongoing projects and are restricted: their page and DOI are public, but their files are only for people the owner gives access, on request from the record's page or through a share link.

## Adding a dataset

Add a row when a dataset gets a DOI, open or restricted:

- **DOI:** the one for all versions, which Zenodo shows as "Cite all versions". It always leads to the latest version.
- **Access:** open, or restricted.
- **Schema version:** the version of the format its latest version follows.
- **Status:** ongoing while data are still being added, or finished.
- **Contact:** who to ask about the dataset, or for access to it.
